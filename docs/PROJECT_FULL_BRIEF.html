1. One-line pitch

UPI Scam Shield ek hybrid AI + rule-based system hai jo UPI/payment scams ko text ya screenshots (OCR) se detect karta hai—risk level, scam verdict, reasons, actions deta hai; optional LLM aur adaptive learning (SQLite + user feedback).

Use case: Hackathon / enterprise demo—consumer safety + support triage.

2. Problem & impact

ProblemImpact
UPI/SMS/WhatsApp scams (OTP, fake links, collect trick, remote access)Financial loss, account takeover
Users ko quickly safety judge karna mushkilGalat trust → payment / leak
Support teams ko consistent triageFaster resolution, fewer false escalations

3. High-level architecture

User (Web UI) │ ▼ FastAPI (backend/app/main.py) │ ├── Text path ─────────────────────────────────────┐ │ │ └── Image path ──► OCR (Tesseract) ──► text ──────┤ │ ▼ Pipeline (pipeline.py) ┌───────────────────────────────────────────────────────────┐ │ • Rules engine (deterministic patterns, severity) │ │ • Intent layer (intent + risk boost) │ │ • Context layer (sender / transaction / user type) │ │ • Adaptive phrases (SQLite — feedback se learned) │ │ • LLM (OpenRouter) — optional intent + explanation enrich │ │ • Risk scoring → LOW / MEDIUM / HIGH │ │ • Decision merge (rules + AI) │ │ • Explanation generator │ └───────────────────────────────────────────────────────────┘ │ ▼ JSON: risk, is_scam, confidence, reasons, actions, explanation, intent, personalization, adaptive, analysis_log_id, …

Principles: Rules-first (no API key = rules-only); hybrid merge; verbose mode for evidence.

7. Adaptive learning

  • analysis_log_id se feedback link hota hai.
  • User SCAM/NOT_SCAM mark karta hai—misclassification par phrases learn ho sakte hain.
  • Baad mein adaptive boost + UI mein Learning badge / boost bar.
  • Demo: /analyzer?demo=learn ya Learning demo button.
